# Poke Rips Brand Kit

## Logo
Primary: Horizontal wordmark with Pokéball on the left.
- Yellow (#FFCB05) letters
- Deep Navy (#003A70) outline
- Dark background preferred

## Colors
| Name            | Hex       | Usage                    |
|-----------------|-----------|--------------------------|
| Poke Yellow     | #FFCB05   | Logo, CTAs, highlights   |
| Pokéball Red    | #EE1515   | Accents, rare alerts     |
| Deep Navy       | #003A70   | Outlines, headers        |
| App Background  | #0B0F1A   | Main bg                  |
| Surface         | #151C2C   | Cards, packs, modals     |
| Text Primary   | #F8FAFC   | Headings                 |
| Text Muted     | #94A3B8   | Secondary text           |

## Typography
- Headings: Inter Black / Bold
- Body: Inter Medium
- Special: Slightly condensed for rarity labels

## Tone of Voice
Playful + degen + clear. 
Examples:
- "Rip a pack. Catch a bag."
- "Gotta pull 'em all."
- "Hold $POKE. Boost your odds."
